# Homebrew tap for Atlas

```bash
brew install raoulg/tap/atlas          # the latest release
brew install --HEAD raoulg/tap/atlas   # the nightly line (`next`), built from source
```

[Atlas](https://github.com/raoulg/atlas) draws what a program is, beneath the language it is written in.

`Formula/atlas.rb` installs the release binary for the machine. Its version and checksums are
written by the release workflow of Atlas after each `v*` tag; do not edit them by hand.
